# Shri Radha Rani - Divine Reveal Animation in Python ✨🌸

A creative coding project celebrating the auspicious occasion of **Radha Ashtami**. This application implements a dynamic, bottom-up scan reveal with glowing golden aura lines and floating divine sparkles using Python, OpenCV, and Pygame.

---

## 🌟 Features
* **Bottom-Up Divine Scan:** Gradually reveals the portrait from the base upwards with smooth interpolation.
* **Golden Aura Beam:** A layered, radiant light beam that leads the reveal animation.
* **Ambient Floating Sparkles:** Continuously rising golden particles and bursts that shimmer across the canvas.
* **Crystal-Clear HD Finish:** Automatically transitions into an ultra-sharp, high-definition render upon completion.
